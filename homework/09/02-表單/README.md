# 作業02：表單

## 概述
製作一個學生問卷調查表。

## 內容
- 基本資料欄位（姓名、密碼、郵件、電話等）
- 使用fieldset分組
- 表單控制項（input、textarea、select等）

## 技術
- HTML 5 Form Elements
- CSS 樣式設計
- 表單元素排版

## AI使用說明
本作業未使用AI，為原創作品。

## 複製說明
本作業為原創設計，未複製他人程式碼。

## 個人貢獻
- 完整設計表單結構
- 自主決定表單欄位內容
- 獨立實現所有表單功能

## 檔案列表
- `表單` - HTML檔案

## 執行方式
用瀏覽器直接開啟HTML檔案即可。

## 功能說明
- 包含基本資料、學習狀況、興趣等多個fieldset
- 使用不同的input類型（text、password、email、tel等）
- 支援提交表單
