# OpenCode 網誌專案

這是一個使用 Node.js + Express 開發的簡易網誌系統，包含使用者認證、文章管理、私人/公共貼文等功能。

---

## 製作過程

### 第一階段：基礎網誌系統 (blog1)
1. **環境建構**：使用 Express 框架建立伺服器
2. **資料庫**：使用 sql.js (SQLite in-memory) 儲存資料
3. **認證系統**：使用 bcryptjs 密碼雜湊 + express-session 管理 session
4. **Markdown 支援**：整合 marked 套件渲染 Markdown 文章
5. **基本 UI**：建立首頁、文章列表、登入/註冊表單

### 第二階段：私人/公共貼文功能 (blog1)
1. **資料庫擴充**：在 posts 資料表新增 `is_public` 欄位
2. **權限控制**：私人貼文僅作者本人可查看
3. **發布選擇**：發文時可選擇是否發布至公共區
4. **界面優化**：新增標籤顯示私人/公開狀態

### 第三階段：美化與主題切換 (blog2)
1. **視覺美化**：卡片式設計、漸變背景、動畫效果
2. **深色模式**：使用 CSS 變數實現主題切換
3. **互動優化**：hover 效果、淡入動畫、按鈕樣式
4. **響應式設計**：支援手機/平板瀏覽

---

## 製作理念

1. **簡單直觀**：不使用複雜框架，以原生 HTML/CSS/JS 實現
2. **漸進式開發**：從基礎功能逐步擴充，而非一次到位
3. **使用者體驗**：注重介面美觀與操作流暢度
4. **安全性**：密碼雜湊、XSS 防護、權限控制

## 使用說明

### 環境需求
- Node.js (建議 v16 以上)
- npm

### 安裝步驟

```bash
# 進入專案目錄
cd "_wp\homework\opencode\blog 1"  # 或 blog 2

# 安裝依賴
npm install

# 啟動伺服器
npm start
```

### 訪問網站
- 本地端：http://localhost:3000

### 操作流程

1. **註冊帳號**：訪問首頁，點擊「註冊」建立帳號
2. **登入系統**：使用帳密登入
3. **發布文章**：點擊「寫新文章」，輸入標題與內容
4. **選擇公開/私人**：勾選「發布到公共貼文區」選項
5. **瀏覽文章**：公共區所有人可見，私人區僅自己可見
6. **切換主題** (Blog2)：點擊右上角 🌙 按鈕

## 技術栈

- **後端**：Express.js
- **資料庫**：SQLite (sql.js)
- **模板引擎**：HTML (內嵌)
- **認證**：bcryptjs + express-session
- **Markdown**：marked
